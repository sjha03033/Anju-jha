# Anju-jha

A home for small, browser-based tools.

## Projects

### Resume Builder
Fill in your contact details, profile, skills, work experience, and education. The page creates a clean, single-column resume preview that you can print or save as a PDF. It can also prepare a factual AI prompt for a professional summary.

- [Open the resume builder source](resume-builder.html)
- Your details stay in the current browser page; the app does not upload or save them. The AI prompt is shared only if you choose to copy and send it to ChatGPT.
- Use the **Print / Save as PDF** button after filling in your details.

### Pocket Ledger
A responsive expense tracker with category filters and weekly, monthly, and lifetime totals.

- [Open Pocket Ledger](index.html)
- Expenses are saved in this browser's local storage and are not sent to a server.

## Run a project

Download its HTML file and open it in a modern browser. No install or build step is needed.
